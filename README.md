# Zapret GUI

Графический лаунчер BAT-профилей сборки Zapret. .NET 8, WPF, MVVM без сторонних фреймворков.

## Запуск

    dotnet run

Для работы WinDivert нужны права администратора. Если приложение запущено без них,
на панели управления появится кнопка «Перезапустить от администратора».

## Возможности

- Поиск BAT-профилей в папке Zapret, запуск и остановка (cmd.exe, перехват stdout/stderr)
- Автовыбор профиля: сохранённый -> проверка зависимостей (winws.exe, WinDivert64.sys) -> минимальная длина имени
- Системный трей: контекстное меню, цветная иконка состояния, сворачивание при закрытии
- Тёмная и светлая темы с переключением на лету
- Проверка доступности YouTube / Discord / Telegram / Google
- Автозапуск с Windows, запуск профиля при старте, запуск свёрнутым
- Один экземпляр приложения
- Настройки хранятся в %AppData%\ZapretGuiPreview\settings.json
